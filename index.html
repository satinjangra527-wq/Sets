1. Cardinality (Numerical) Formulas & Key Words

Essential set counting formulas and problem identification keywords

Section 1.1

1.1 Union for Two Sets

$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$

Key Words:

"At least one" "Either A or B" "Total / Total students/people" "Or"
Section 1.2

1.2 Intersection for Two Sets

$$n(A \cap B) = n(A) + n(B) - n(A \cup B)$$

Key Words:

"Both" "Common (elements present in both)" "And"
Section 1.3

1.3 Only A ($A - B$)

$$n(A - B) = n(A) - n(A \cap B) = n(A \cup B) - n(B)$$

Key Words:

"Only A" "A but not B"
Section 1.4

1.4 Only B ($B - A$)

$$n(B - A) = n(B) - n(A \cap B) = n(A \cup B) - n(A)$$

Key Words:

"Only B" "B but not A"
Section 1.5

1.5 Cartesian Product

$$n(A \times B) = n(A) \times n(B)$$

Key Words:

"Cartesian Product" "Ordered pairs (total number of ordered pairs)"
Section 1.6

1.6 Complement Count

$$n(A') = n(U) - n(A)$$

Key Words:

"Not A" "Complement of A"
Section 1.7

1.7 Symmetric Difference

$$n(A \Delta B) = n(A - B) + n(B - A) = n(A \cup B) - n(A \cap B)$$

Key Words:

"Exactly one of them (either only A or only B)" "Symmetric Difference"
Section 1.8

1.8 Disjoint Sets

$$n(A \cup B) = n(A) + n(B) \iff A, B \text{ are disjoint sets}$$

Key Words:

"Disjoint sets (sets with no common elements)" "Nothing in common / Mutually exclusive" "When $n(A \cap B) = 0$ or $A \cap B = \phi$ (empty / null set) is given."

2. Formula for Three Sets

$$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C)$$

Usage Application:

Used when three sets (such as A, B, and C) are given in the problem and total count is to be calculated.

3. De Morgan's Laws

$$(A \cup B)' = A' \cap B'$$
$$(A \cap B)' = A' \cup B'$$

Complement swaps Union $(\cup)$ with Intersection $(\cap)$ and vice-versa.

4. Distributive Laws

$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

Distributes operation over parentheses similar to algebraic multiplication.

5. Complement & Involution Laws

Rules governing universal sets, empty sets, and double complements

$$A \cup A' = U$$ (Universal Set)
$$A \cap A' = \phi$$ (Empty Set / Null Set)
$$(A')' = A$$ (Involution Law - returning to original)
$$U' = \phi$$ (Complement of Universal is Null)
$$\phi' = U$$ (Complement of Null is Universal)

6. Laws Related to Difference

Converting set difference into intersections and complements

Intersection Conversion: $$A - B = A \cap B'$$

(To convert difference into intersection)

Reverse Difference: $$B - A = B \cap A'$$

(Difference of B and A)

Difference over Union: $$A - (B \cup C) = (A - B) \cap (A - C)$$
Difference over Intersection: $$A - (B \cap C) = (A - B) \cup (A - C)$$

7. Commutative & Associative Laws

7.1 Commutative Laws

$$A \cup B = B \cup A$$
$$A \cap B = B \cap A$$

Order of sets does not affect the result.

7.2 Associative Laws

$$(A \cup B) \cup C = A \cup (B \cup C)$$
$$(A \cap B) \cap C = A \cap (B \cap C)$$

Grouping of sets does not affect the result.

8. Identity & Idempotent Laws

8.1 Identity Laws

$$A \cup \phi = A$$
$$A \cap U = A$$

Empty set $\phi$ is identity for $\cup$; Universal set $U$ is identity for $\cap$.

8.2 Idempotent Laws

$$A \cup A = A$$
$$A \cap A = A$$

Operating a set with itself yields the same set.
